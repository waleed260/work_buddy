## 2026-05-13 - Visual Hierarchy in Text-based Interfaces
**Learning:** In a CLI or chat-based interface, users can easily lose track of importance when tasks are presented in a simple list. Using consistent color-coded emojis (🔴, 🟡, 🔵) combined with priority sorting creates an immediate visual hierarchy that helps users focus on what matters most first.
**Action:** Always implement sorting by priority for task/event lists and use consistent visual markers for severity or priority levels across all status-related outputs.

## 2026-05-16 - Chronological Intuition and Delightful Empty States
**Learning:** In text-heavy productivity tools, temporal lists (schedules) must be sorted chronologically to match user mental models. Additionally, "empty states" are missed opportunities for engagement; replacing clinical "no items" with encouraging copy and positive emojis (🎉, ✨) significantly enhances the "assistant" persona.
**Action:** Always sort calendar/schedule data by time and implement warm, encouraging empty state messages for all list-based features.
